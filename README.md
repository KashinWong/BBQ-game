# 烤串高手

手机竖屏夜市烤串小游戏。当前版本完成了正式 MVP 的第 1 关垂直切片，玩家可以从关卡准备进入互动教学，完成“选料—上签—烤制—翻面—出餐—得分—结算”的完整流程。

## 本地试玩

```bash
npm install
npm run dev
```

打开终端显示的地址即可游玩。主要适配 390×844 的 9:16 竖屏，并兼容常见手机尺寸与安全区；横屏手机会提示旋转设备。

## 第 1 关内容

- 90 秒限时，600 / 1000 / 1400 分对应一至三星。
- 牛肉、青椒、蘑菇始终各显示两份，取走后原位快速补货；单订单固定两块且不重复。
- 点击食材自动上签、加大签子抓取区、两个烤位、双面熟度、点击翻面和拖动出餐。
- 首次动作驱动教学；教学期间冻结关卡与订单倒计时，但烤制正常推进。
- 动态订单耐心、错误拒收、熟度评分、速度奖励和连击倍率。
- 达标即时反馈、暂停菜单、完整统计与成功/失败结算。
- 本地保存教学完成状态、最高分、最高星级和第 2 关解锁状态。
- 浏览器短音效与可选轻振动；不支持时自动静默降级。

## 操作

- 点击订单要求的食材，食材自动飞入当前签子。
- 把配好的生串拖到烤位；点击烤串翻面。
- 蓝色和橙色细条分别显示两面熟度；进入 `70–115` 最佳区后变金色，两面都变金后拖到订单出餐。
- 生串可拖到待烤托盘；拖到垃圾桶撤下最后一块，停留 0.6 秒清空整串。
- 右上角暂停按钮可继续或重新开始本关。

## 质量检查

```bash
npm test
npm run typecheck
npm run build
npm audit
```

行为测试覆盖第 1 关配置、计分拒收、订单耐心、备料布局、教学流程与本地进度。Phaser 当前仍为单包加载，生产构建会提示主包偏大，后续内容关开发时应拆分启动页与关卡资源。
