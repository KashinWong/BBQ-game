# 烤串高手

手机竖屏夜市烤串小游戏，当前是可完整试玩的六关网页 MVP。玩家在 90 秒内完成订单，通过选料、上签、双面烤制、翻面和出餐获得积分并逐关解锁。

## 本地试玩

需要 Node.js `20.19.x` 或 `22.12.0+`。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址即可游玩。游戏按 390 x 844 的竖屏手机设计，兼容常见手机尺寸与安全区；横屏手机会显示旋转提示。开发环境可用 `?previewLevel=6` 直接查看第六关。

## 游戏内容

- 六个可连续解锁的关卡，最终关同时处理双订单、三烤位和移动食材。
- 每关 90 秒，一星即可解锁下一关，并本地保存最高分和最高星级。
- 首关提供动作驱动教学；后续关卡逐步增加食材、订单复杂度和备料移动速度。
- 主菜单与暂停弹窗均可打开设置，音乐、音效和振动偏好会立即生效并保存在浏览器本地。当前没有背景音乐资源，音乐开关已为后续接入保留。

## 操作

- 点击订单所需食材，食材会自动上到当前备料签。
- 拖动生串到空烤位，点击烤串翻面。
- 蓝色和橙色熟度条分别表示两面；两面进入金色最佳区后，把烤串拖到匹配订单。
- 备料区的签子拖到垃圾桶可撤下最后一块；在垃圾桶上停留后松手可清空整串。托盘和烤架上的串拖到垃圾桶会整串丢弃。
- 右上角暂停按钮可继续、调整设置、重开本关或返回选关。

## 质量检查

```bash
npm test
npm run typecheck
npm run build
npm audit
```

测试覆盖关卡配置、计分与订单规则、解锁存档、移动食材、设置持久化、反馈开关和垃圾桶规则。

## 静态部署

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`，资源路径使用相对地址，可将该目录内容部署到任意静态文件托管服务，无需服务器路由或环境变量。
