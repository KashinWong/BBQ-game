# 烤串高手

手机竖屏烤串小游戏的灰盒原型，用于验证“串料—烤制—翻面—出餐”的核心操作与画面布局。

> 这是用于验证核心手感的灰盒原型，不是正式产品代码。布局对比已经结束，当前只保留获选的“上下工作台”。

## 开始试玩

```bash
npm install
npm run dev
```

打开终端显示的本地地址。推荐先使用浏览器手机模拟尺寸或直接用手机访问局域网 Network 地址。

默认页面即为获选的“上下工作台”，直接访问 `/`，不再需要 `?variant=` 参数。

## 操作

- 点击订单要求的食材，食材会自动飞入当前签子。
- 把完成的生串拖到烤位或待烤托盘。
- 点击烤架上的烤串翻面。
- 蓝色与橙色细条分别显示正反面熟度；两面进入理想区间后拖到订单出餐。
- 拖到垃圾桶撤下最后一块，停留 0.6 秒清空整串。
- 右上角按钮立即重开本局。

## 验证

```bash
npm run typecheck
npm run build
```
