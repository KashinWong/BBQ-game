## 已确认目标

六种食材是牛肉 `beef`、青椒 `pepper`、蘑菇 `mushroom`、香肠 `sausage`、玉米 `corn`、鸡肉 `chicken`。每种准备 `raw`、`cooked`、`burnt` 三态，共 18 张独立图片的提示词。

每张只包含一个不带竹签的食材单元，供备料区与烤串组合复用。“生”指尚未放上烤架的初始外观，不承诺食材生产工艺上的生熟状态。

只制作三种基础外观，不将游戏内部的六个熟度阶段等同于三张图片。中间熟度过渡、正反面显示、烟火与粒子效果属于后续接入设计；本次不改动熟度、计分、关卡或接口。

## 统一美术规范

| 项目 | 约定 |
| --- | --- |
| 画风 | 清晰描边卡通，圆润造型，深棕外轮廓，简单两到三层明暗，少量高光 |
| 视角 | 近似正交的轻微斜俯视，顶部为主，露出少量前侧面 |
| 光照 | 左上方柔和暖光，仅保留物体自身明暗，无地面投影 |
| 构图 | 单件居中、完整不裁切，主体最长边约占画布 75%，横向食材长轴水平 |
| 输出目标 | 1024×1024 PNG，真实透明 alpha，无棋盘格假背景或白色贴纸边框 |
| 小尺寸预览 | 备料区约 42×36、烤串约 34×31 逻辑像素，按实际大小检查 |
| 三态一致性 | 同一食材维持位置、尺寸、朝向、轮廓与锚点；主要改变表面颜色、烤痕和油光 |
| 焦态 | 明显焦糊且仍可辨认，保留部分本色，禁止统一涂成黑块 |
| 排除内容 | 竹签、餐具、背景、文字、水印、拟人五官、烟火、粒子、多件食材、拼图、写实摄影 |

目标尺寸与透明背景是输出要求，仍需在实际生成后核验；文字要求不代表生成工具必然输出符合规格的文件。

## 主体辨识

| 食材 | 主要轮廓 | 生图辨识点 |
| --- | --- | --- |
| 牛肉 | 圆角方块 | 红粉肉色、两条简化脂肪纹，不能生成整块牛排 |
| 青椒 | 宽扁弯曲片、波浪外缘 | 鲜绿色、浅色内壁，不能生成整颗青椒 |
| 蘑菇 | 宽菌盖、短粗柄的伞形 | 奶油米白色，不能生成红色带点的装饰蘑菇 |
| 香肠 | 横向粗短圆柱 | 珊瑚红表皮、浅粉切面，不能生成带面包的热狗 |
| 玉米 | 横向厚切短圆柱 | 淡黄大颗粒、清楚排列，不能生成整根玉米棒 |
| 鸡肉 | 不规则圆角三角厚块 | 浅桃粉色、浅色筋膜，不能生成带骨鸡腿 |

主体描述和每种熟态、焦态变化的完整文本见 [prompts.md](./prompts.md)。

## 后续生成顺序

1. 生成并选择 `beef-raw.png`，锁定整体画风。
2. 分别从该生牛肉图编辑熟态、焦态，检查三态对齐和缩小后的可读性。
3. 以生牛肉图作为画风参考，依次生成其余五种生食材图。只参考风格，不复制牛肉形状。
4. 每种食材分别从自己的生图编辑熟态与焦态，不能从熟图继续生成焦图。
5. 每次仅生成一张独立图；检查通过后再统一整理裁切与图集，不让生成模型一次绘制 18 格图集。
6. 按 [验收清单](./smoke-test.md)检查真实 alpha、边缘、三态对齐和实际大小下的辨识度；每次只针对一个问题返修。
